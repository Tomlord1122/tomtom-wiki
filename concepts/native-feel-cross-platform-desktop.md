# Native-Feel Cross-Platform Desktop

Tauri 2 positions a cross-platform desktop stack around an OS-native web renderer, a frontend-independent UI, Rust application logic, and system integration through Swift and Kotlin. This can reduce package size and centralize security concerns, but native-feel quality still depends on input handling, windowing, accessibility, updates, and platform-specific testing.

**Working implications:** choose the web frontend independently, keep privileged capabilities narrow, and test each OS as a product—not merely as a build target.
