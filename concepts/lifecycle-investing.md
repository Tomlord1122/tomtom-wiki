# 生命週期投資法

生命週期投資法（Lifecycle Investing）是一種以人生階段為基礎的投資策略，核心概念是：**年輕時（人力資本充足、金融資本較少時）透過槓桿提高曝險，隨著年齡增長再逐步降低。**

## 為什麼年輕時應該提高曝險

大仁用 1992～2021 年的台股數據回測：
- 每年定期定額 1 萬，總投入 30 萬 → 最終 145 萬
- 定存情境 → 最終 40 萬

定期定額雖然勝過定存，但大仁指出：年輕時如果只做定期定額，等於浪費了最寶貴的資源——**時間**。

## 核心原則

1. **人力資本 vs 金融資本**：年輕時，你最大的資產是未來的工作收入（人力資本），而不是已經存下的錢（金融資本）。生命週期投資法主張用未來收入做擔保，提前提高市場曝險。

2. **槓桿是時間的朋友**：越年輕，承受波動的時間越長，複利效果越明顯。早期的波動在長期中會被平滑。

3. **逐步去槓桿**：隨著年齡增長、金融資本累積，應逐步降低槓桿，保護已有的資產。

## 實現工具

- 信用貸款（對人力資本開槓桿）
- 股票質押（對金融資本開槓桿）
- 槓桿 ETF（如 00631L 正2）
- 房貸增貸

## 與定期定額的比較

| 面向 | 定期定額 | 生命週期投資法 |
|------|---------|--------------|
| 早期曝險 | 低（慢慢累積） | 高（提前拉高） |
| 所需本金 | 有閒錢就能做 | 需要借貸能力 |
| 風險來源 | 市場下跌 | 市場下跌 + 槓桿風險 |
| 適合對象 | 所有人 | 有穩定收入的年輕人 |
| 長期潛在報酬 | 中等 | 可能更高 |

## 風險與限制

1. 需要穩定的現金流來支撐還款。
2. 早期波動可能遠高於定期定額，心理壓力較大。
3. 槓桿可能放大虧損，需要嚴格的風險管理。
4. 不適合沒有穩定收入的投資人。
5. 需要理解並接受「波動不等於風險」在長週期中的意義。
